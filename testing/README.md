# Pruebas automatizadas realizadas en Cypress para CAPACIA 

**Responsable principal:** - — Pamela Calafate - QA Tester

- Contiene:

- `cypress/e2e/`: los scripts de pruebas automatizadas (`api-status.cy.js`, `benchmark.cy.js` y `capacia.cy.js`).
- `cypress/support/`: archivos de configuración/soporte de Cypress.
- `cypress/fixtures/`: datos de prueba.
- `cypress.config.js`: configuración de Cypress.
- `package.json` y `package-lock.json`: dependencias necesarias para ejecutar las pruebas.
