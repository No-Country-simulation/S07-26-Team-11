# assets/

Activos de marca listos para usar en codigo.

```
logo.svg              logo principal, vectorial
logo-mono.svg         version monocromatica para el PDF
icons/                iconos en SVG
fonts/                archivos de fuente (woff2 para web, ttf/otf para el PDF)
```

**Importante sobre las fuentes:** para incrustarlas en un PDF, la licencia de la
tipografia debe permitirlo explicitamente. Muchas fuentes comerciales lo prohiben
o lo cobran aparte. Verificalo ANTES de disenar con ellas: cambiar la tipografia
a mitad del proyecto rehace todo el documento.
